# Velvet Tiger logos

Typographic wordmarks in **Syne SemiBold** (matches the site), outlined as vectors — no font install required to use.

| File | Layout | Color |
|------|--------|-------|
| `velvet-tiger-horizontal-ink` | One line | Ink `#141414` |
| `velvet-tiger-horizontal-white` | One line | White |
| `velvet-tiger-horizontal-accent` | One line | Teal `#0E4D4A` |
| `velvet-tiger-stacked-ink` | Velvet / Tiger | Ink |
| `velvet-tiger-stacked-white` | Velvet / Tiger | White |
| `velvet-tiger-stacked-accent` | Velvet / Tiger | Teal |

Each variant ships as `.svg` and `.png` (transparent RGBA).

Syne is licensed under the SIL Open Font License — see `OFL-Syne.txt`.

Regenerate: `node scripts/generate-logos.mjs` (requires Syne VF in `logos/.tmp/Syne.ttf`).
